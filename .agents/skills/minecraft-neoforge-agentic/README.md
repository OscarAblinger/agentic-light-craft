# Minecraft NeoForge Agentic Coding Skill

This package contains a project-specific agent skill for implementing Minecraft Java Edition mods.

Target contract:

- Minecraft 26.1.x
- NeoForge
- JDK 25
- Gradle
- Official NeoForge MDK/project generator

Install/copy the `minecraft-neoforge-agentic` directory into the agent's skill directory.

The skill intentionally does not replace the project's `minecraft-mod-setup.md`; it instructs the agent to treat that file as the repository-level source of truth.
