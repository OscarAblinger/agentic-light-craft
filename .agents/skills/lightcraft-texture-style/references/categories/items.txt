# LightCraft texture category: ITEMS
# ============================================================================
# Directives below are read by TextureCheck (see ../checker-policy.md);
# everything else is human-reviewed drawing rules.
# ============================================================================

name: items
allow: marble, lapis, gold, lux, outline
opaque-only: false
tiling: none
max-colors: 16

# --- How a basic item is built ----------------------------------------------
#
# BACKGROUND Items sit on a transparent background - only the object is drawn.
#            Leave every other pixel fully transparent (alpha 0).
#
# ALPHA      Partial transparency (alpha 1-254) is allowed for items, typically
#            as deliberate soft glow or soft edges (for example the lapis lux
#            gems). The checker reports partial pixels for confirmation. Full
#            blocks forbid partial alpha entirely (see blocks/machines/ores).
#
# SILHOUETTE The shape must read at 16px on any inventory background. Give the
#            object a dark outline (outline.deep, or outline.mid for a softer
#            edge) so it separates from the background and from neighbours.
#            This is the main difference from machines, which bevel instead.
#
# BUDGET    Keep the color count low. A tight ramp reads cleaner than a
#            gradient. The soft limit here (16) is lower than machines (24).
#
# LIGHT     Light from the top-left, same as machines. Mid-tone body, darker
#            outline, lighter top-left facets.
#
# MATERIALS Use the same materials as machines so the set feels like one world:
#            marble for stone parts, gold for metal parts, lapis for gems, and
#            lux for anything that emits (for example a lapis-lux ingot).
#            Luxflower petals, seeds and petal bundles are plant items - they
#            use the plants category instead.
#
# TILING    Not applicable - items do not tile (directive: tiling: none).
# ============================================================================
