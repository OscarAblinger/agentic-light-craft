# Directives below are read by TextureCheck (see ../checker-policy.md);
# everything else is human-reviewed drawing rules.

name: blocks
allow: marble, lapis, gold, lux, outline
opaque-only: true
tiling: required
max-colors: 24

# --- How a material block is built ------------------------------------------
#
# WHAT      Full 16x16 cube faces for solid material blocks - the lapis lux
#           storage blocks (raw and ingot) and similar plain blocks. Ores are
#           a separate category (ores.txt) because their stone background is
#           palette-exempt.
#
# BODY      Draw from the same ramps as machines and items so the whole set
#           reads as one world: lux/gold for lapis lux blocks, marble for
#           stone blocks.
#
# SHADING   Bevel instead of outline: specular top-left, deep bottom-right.
#           Do not draw a border ring around the face - storage blocks must
#           read level next to each other in a wall.
#
# OPAQUE    Full blocks are opaque: alpha 0 or 255 only (directive:
#           opaque-only: true).
#
# TILING    Faces must tile seamlessly (directive: tiling: required). Review
#           the *.3x3.png preview.
#
# LIGHT     Top-left, consistent with everything else.
# ============================================================================
