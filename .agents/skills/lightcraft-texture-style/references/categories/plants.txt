# LightCraft texture category: PLANTS
# ============================================================================
# Directives below are read by TextureCheck (see ../checker-policy.md);
# everything else is human-reviewed drawing rules.

name: plants
palette: exempt
opaque-only: false
tiling: none
max-colors: 64

# --- How a plant is built ---------------------------------------------------
#
# PALETTE   EXEMPT on purpose: plants keep their own greens, browns and petal
#           colours instead of being forced into the core palette. The checker
#           skips palette adherence for this category; the structural checks
#           (dimensions, transparency reporting, budget) still run. The ore
#           stone background (ores.txt) is the only other exemption.
#
# WHAT      The luxflower crop stages (block/luxflower_stage0..7.png, 16x16
#           cross-model textures) and their drop items (luxflower_petal,
#           luxflower_seeds, petal_bundle, small_petal_bundle,
#           double_petal_bundle, triple_petal_bundle, quadruple_petal_bundle).
#
# ALPHA     Partial transparency is allowed, as for items - typically soft
#           glow or soft petal edges. The checker reports partial pixels for
#           confirmation.
#
# LIGHT     Top-left, consistent with everything else. Later luxflower stages
#           are brighter (the bloom emits light).
#
# BUDGET    Loose cap (64); it only guards runaway noise on small art.
#
# TILING    Not applicable - crops use cross models and items do not tile
#           (directive: tiling: none).
# ============================================================================
