# Light Book documentation structure

This file is the living reading-order map (information architecture) of the
Light Book (`lightcraft:light_book`) and is maintained by the
`in-game-documentation` skill.

- The skill creates and maintains this file; it does not prescribe a structure
  of its own, so this map must be updated as the book grows.
- Audits read the book in the order defined here and ignore extra information in
  the map that is not part of the book structure.

## Categories

### Getting Started (`getting_started`)

LightCraft's in-game guide. The entry point of the book; the first place a player
looks.

### Pocket Dimension (`pocket_dimension`)

LightCraft's private pocket cubes: what they are, how to use them and how to
grow them.
